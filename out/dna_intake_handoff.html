DnA Intelligent Intake & Automation — Handoff Guide

Summer 2026 · Workiva Data & Analytics · Author: Eva Li

System Overview

Stakeholders submit data requests via a Jira portal form, a Slack message to the DnA Assistant bot, or a /dna slash command (in progress). AI by Workato classifies the request, generates a draft ticket, and posts it to a Slack triage channel. A human approves or edits, and the ticket is created in the DNA Jira project with all required fields pre-filled.

Core Workflows

  • Jira Portal Intake: Stakeholder submits a DATA-project ticket via the redesigned portal form (5 structured fields: service type, impact, timeline, data domains, description template). New ticket triggers the AI enrichment pipeline.
  • Slack Bot Intake: DnA Assistant Genie infers fields from conversation context and only asks for what it cannot infer. Optional fields output an empty string — never placeholder text like "N/A". On confirmation, a DATA ticket is created and flows into the same pipeline.
  • AI Parsing & Auto-Comment: New Jira issue → analyze text → parse fields → write to DNA Jira Ticket table → post to Slack → auto-comment on original ticket with expected review timeline (Blocker: immediately; High: next business day; Medium: 2–3 days; Low: 5 days).
  • Triage → Approve / Edit → Migration: Approve creates the DNA ticket directly. Edit opens a Slack modal for corrections first. Either way: DNA ticket is created, a cross-reference comment links the two tickets, and the original DATA ticket gets a comment and closes.
  • Human Takeover: If a DnA team member replies in a thread that isn't their own, the thread is flagged and the bot goes silent. Category 3 messages (explicit bot requests) bypass this so the bot can still act on a flagged thread if asked.

Known Issues — Check Before Debugging

Issue What to do
Jira enum field mismatch (ticket creation fails silently) AI must output the complete Jira option string, including any parenthetical. Use DNA Genie | Service Type Mapping lookup table for fields where short AI output needs to map to a longer Jira display string.
Components field type mismatch From Slack modals (multi_static_select): already an array — drag the datapill in directly. From AI text output: may be a comma-separated string — use .split(","). Never run .gsub on a datapill that is already an array.
DNA project missing fields (screen error) reporter, due date, and some custom fields throw "Field cannot be set" errors. This is a Jira screen configuration issue — ask Jira Admin to add the field to the DNA project Create/Edit screens.
Issue link fails ("No link type found" or "Issue Does Not Exist") Use a comment on both tickets cross-referencing each other's key as a fallback. If revisiting formal links, confirm the exact link type name in Project Settings → Issue Linking first.
Slack message shows "New message" or blank Block exceeded Slack's 3000-character limit. Split long fields into a separate block or truncate with a link to the ticket.
Edit Jira Ticket Command high failure rate (4 / 38 successful) Investigate recent failed job logs before relying on the Edit path. Likely cause: Components field type issue or missing DNA screen field. The Approve path is stable.
Optional fields showing "Not mentioned" or "N/A" in tickets Verify the Genie skill prompt still instructs the AI to output an empty string for optional fields — check if this instruction was edited out during a recent prompt change.
/dna slash command registered but not firing Confirm trigger is New slash_command event to Slack Workbot (not HTTP polling). Confirm the Slack App the slash command is registered under matches the App Workato's Workbot connection is authenticated as — check the Connections page.

Quick Troubleshooting Reference

Symptom Likely cause Where to look
Bot doesn't respond to a message Classified as Category 1, or thread is in Human Takeover DnA Human Takeover table; classification step in Handle Slack Notifications
Bot keeps responding after a teammate replied That person's Slack User ID is not in DnA Team Member Add their ID to the DnA Team Member table
Ticket creation fails with a field error Enum string mismatch, missing DNA screen field, or wrong data type Known Issues above; check exact string, screen config, array type
Slack message shows placeholder or garbled text Block over 3000-char limit, or field is genuinely null Check DNA Jira Ticket table record for that ticket_key
Approve / Edit button does nothing Staging table lookup failed or ticket_key not passed correctly Check button recipe's search step against DNA Jira Ticket table
Bot says "previous request still processing" Conversation session state didn't reset Agentic Conversation External IDs table — find the thread record and reset its status
