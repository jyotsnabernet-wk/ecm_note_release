Release Notification

Semantic views, Customer360 hierarchy, product &amp; GES events, FedRAMP WDesk cutover, platform upkeep

What is happening

This week's DnA release covers the following Analytics Engineering stories.

  • Support — semantic view evaluation & actions
    • The obt_support_ticket Support Ticket semantic view was evaluated and hardened for Text-to-SQL performance in Cortex Analyst, using the Data Science evaluation framework, ahead of exposing it to the GTM Assistant in Claude via MCP.
    • Work is still in progress to define and implement Signals & Actions for the sv_support_ticket semantic view, aligned with business stakeholders on the required list.
    • (DNA-6627 / DNA-6249)
  • Customer360 — account hierarchy & parent discovery
    • The D&B API was reviewed as a way to identify all parents of an account at once, instead of gathering the hierarchy one account at a time.
    • The account hierarchy semantic view was verified as a tool in a multi-agent setup, alongside others such as bookings, to confirm it produces accurate answers.
    • (DNA-6036 / DNA-6657)
  • Product usage & GES events — new event facts
    • The new fct_user_analytics_events fact replaces the planned int_user_analytics intermediate model and reads USER_ANALYTIC.CERBERUS_COMMIT directly from the lake, because the silver views cannot prune and the intermediate pattern does not scale.
    • fct_ges_events now includes the SCRIPT_RUN_OPERATION_EVENT topic (modeled in silver as workiva_script_run_operation_event) alongside workiva_event_log.
    • Gen AI feature events are being onboarded into the shared feature events layer (fct_feature_events and related catalog/rules) so Gen AI activity is counted through the standard product usage path. This work is in progress.
    • (DNA-6667 / DNA-6669 / DNA-6728)
  • FedRAMP — WDesk Classic cutover & Workiva merge strategy
    • Multiple parts of the WDesk Classic production cutover are in progress, directly replacing WDesk Classic table references in dbt, with basic QA focused on code compile in a personal SILVER_TEST schema.
    • Workiva models are being switched from append to merge on the appropriate keys to improve speed and data accuracy without losing rows skipped by the OR predicate.
    • Overlord sources are being classified as standardized or custom, with FedRAMP-regulated sources (e.g. Workday) flagged to drive the migration wave plan.
    • (DNA-6437 / DNA-6579 / DNA-6580 / DNA-6581 / DNA-6743 / DNA-6053)
  • Platform — dbt Cloud OAuth & Lambda runtime
    • The dbt Cloud Snowflake OAuth redirect URI was migrated with steps designed to avoid downtime, after the dbt Cloud change had locked users out of onboarding and connection refreshes.
    • Three Lambdas (ito-ds-user-analytic-s3, ito-AnalyticDeaggregator, ito-AnalyticDeaggregator-Reprocessor) are being moved off the Python 3.10 runtime, which AWS is retiring, to the newest feasible Python version. This work is in progress.
    • (DNA-6713 / DNA-6162)
  • GTM & Finance — bookings comparison & forecast history
    • New models are in progress to compare Bookings between reporting points, since obt_bookings reflects the latest Salesforce status and reported month-end or quarter-end numbers can stop matching.
    • FCT_FORECAST_HISTORY is being updated to refresh Wednesday 5pm CT and Thursday 5pm CT instead of weekly on Mondays, with additional Account Owner fields added. This work is in progress.
    • (DNA-6463 / DNA-6346)
  • Data ingestion — Snowflake availability & source assessment
    • The Redshift table cpx_dna.cpxdna_retention_renewal_solution_quarter was brought into Snowflake for a CPX solution churn proof of concept.
    • Zendesk article ingestion is being extended with engagement fields (views, comments, subscriptions, upvotes) for the DX team, and the current Fivetran entitlement, connectors, and MAR cost model are being assessed. Both are in progress.
    • (DNA-4281 / DNA-5171 / DNA-6056)

Why it is happening

Analytics & AI readiness

  • Validating the Support and account hierarchy semantic views makes Text-to-SQL and agent answers trustworthy before wider GTM use.
  • Moving user analytics to a lake-based fact, adding script run events, and onboarding Gen AI feature events give customer and product metrics fuller, more scalable coverage.

Platform, compliance & data access

  • The FedRAMP cutover, merge strategy and source classification prepare the pipelines for FedRAMP-regulated data handling and better performance.
  • The OAuth fix, Lambda runtime upgrade, and ingestion work restore tool access, avoid unsupported runtimes, and give teams the data they requested.

When it will happen

Deploy on

Consumers relying on any changed columns should validate and update downstream references within 30 days of the deploy (2026-11-18).

Downstream impact

  • Support and AI consumers of obt_support_ticket and sv_support_ticket will see an evaluated semantic view, with Signals & Actions to follow.
  • Product usage reporting gains fct_user_analytics_events, and fct_ges_events now includes script run events from workiva_script_run_operation_event alongside workiva_event_log.
  • Anything built on the former int_user_analytics path or fct_product_events wiring should use fct_user_analytics_events instead.
  • Models that reference WDesk Classic tables, and Workiva models moving to merge, may change as the FedRAMP cutover completes.
  • Consumers of FCT_FORECAST_HISTORY and obt_bookings should expect the refresh cadence and new comparison models to change once those in-progress items ship.

Recommended actions

Verify — Downstream users of fct_ges_events and fct_user_analytics_events confirm row counts and event types look as expected, including script run events.

Verify — Any dashboards or queries that referenced int_user_analytics now point to fct_user_analytics_events.

Verify — dbt Cloud users can authenticate to Snowflake and refresh existing connections after the OAuth redirect URI change.
